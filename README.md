# Jhon De Floretto — Portfolio Website

A responsive, multi-section personal portfolio built with vanilla HTML, CSS, and JavaScript. It uses a white/off-white canvas, cream surfaces, and brown accents.

## Included
- `index.html` — page structure and content based on the supplied CV
- `style.css` — responsive design system, CSS illustrations, layout, and animation
- `script.js` — cinematic energy-burst intro with particle effects, scroll reveal, reading progress bar, mobile navigation, and project-detail modals
- `foto-diri.jpg` — your supplied portrait used in the hero section

## Run locally
1. Download and extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Recommended: install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.
5. The website opens in your browser; edits will reload automatically.

You can also open `index.html` directly, but a local server is recommended for a smoother development workflow.

## Personalize before publishing
- Confirm the phone number, email, LinkedIn URL, and GitHub URL.
- Place your final CV PDF in this folder and name it exactly `CV-Jhon-De-Floretto.pdf`; the Home hero has a Download CV button pointing to that file.
- Add a PDF copy of your CV and connect a “Download CV” link if you want that feature.
- Add real screenshots, diagrams, and repository links for each project. The current project visuals are CSS-made illustrations, not screenshots of actual project deliverables.
- Add project outcomes only when you have evidence; this template does not invent impact metrics.
- Review which coursework and team deliverables can be shown publicly before uploading them.
- Consider a custom domain and a professional email address.

## Publish free
### GitHub Pages
1. Create a GitHub repository named `jhon-portfolio` (or your preferred name).
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. In the repository, open **Settings → Pages**.
4. Under build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for deployment and open the URL shown in Pages settings.

## Notes
- Google Fonts needs an internet connection; system font fallbacks are included.
- The scroll effects and intro respect `prefers-reduced-motion`. The cinematic energy-burst intro lasts about 3.5 seconds and can be skipped with the button or Escape key.
- Portfolio content is in English to support international recruiters. You can translate it to Indonesian if preferred.
